# gallery

A gallery-style web application for displaying images in a structured and visually appealing layout.

## Overview
This project is designed to present a collection of images in a gallery interface, with a simple backend and media handling setup.

## Tech Stack
- Python
- Django
- SQLite
- Media handling

## Run locally
1. Create a virtual environment.
2. Install dependencies.
3. Run:

```bash
python manage.py migrate
python manage.py runserver
```

## Purpose
This repository acts as a simple gallery project for web and media-based portfolios or photo showcases.
